# 🎹 Cresendor: HMD를 이용한 실시간 피아노 연습 서포터

> MIDI 데이터 시각화와 실시간 판정 시스템을 활용해 직관적인 사용자 중심 피아노 학습 환경을 구축한 Unity 팀 프로젝트입니다.  
> *(제24회 한국공학대전 월드클래스기업협회상 수상)*

## 🚀 주요 담당 구현 기능 (My Role)

### 1. 매니저 중심 시스템 아키텍처 설계
* 게임 내 전역 데이터와 흐름을 체계적으로 관리하기 위해 매니저 중심의 싱글톤 및 모듈화 구조 설계
* 사운드, 입력, UI, 연주 데이터 매니저 간의 결합도를 낮추고 확장성 있는 흐름 구축

### 2. MIDI 입력 및 실시간 노트 판정 시스템
* 외부 MIDI 장치로부터 입력받은 데이터를 실시간으로 파싱하고, 화면상의 노트 데이터와 동기화하는 로직 구현
* 정확한 타이밍 판정을 위한 시간 동기화 알고리즘 적용

### 3. UI 프레임워크 구조 설계 및 오프셋 보정
* 피아노 학습에 최적화된 직관적인 UI 시스템 전반 설계
* 사용자의 연주 체감 오프선을 실시간으로 보정하는 입력 오프셋 보정 구조를 도입하여 판정 어색함 개선

## 💡 트러블 슈팅 및 배운 점
* **실시간 노트 시각화와 타이밍 오차 해결:** MIDI 입력 데이터와 시각적으로 떨어지는 노트 간의 미세한 밀리초(ms) 단위 오차를 분석하고, 내부 시계 기준 정산 로직을 개선하여 플레이 체감 지연 현상 해결
* **유지보수 용이한 UI 구조 설계:** 초기 개발 시 파편화되던 UI벤트를 중앙 매니저 통신 방식으로 리팩토링하여, 화면 전환 및 상태 관리 시 발생하는 버그 최소화
